## 🔐 Security Best Practices (For Authorized Users)

### **Mandatory Requirements:**

1. **Enable Two-Factor Authentication (2FA)**
   - GitHub account must have 2FA enabled
   - Use authenticator app (not SMS)
   - Backup codes stored securely

2. **Use Environment Variables**
   - Never commit secrets to repo
   - Use `.env` files (gitignored)
   - Rotate credentials every 90 days

3. **Follow Branch Strategy**
   - Never push directly to `main` or `gh-pages`
   - Create feature branches from `develop`
   - Submit PRs for code review

4. **Keep Dependencies Updated**
   - Run `npm audit` weekly
   - Apply security patches within 7 days
   - Lock dependency versions

### **Prohibited Actions:**

- ❌ Sharing access tokens or credentials
- ❌ Committing API keys or secrets
- ❌ Pushing to protected branches without approval
- ❌ Disabling security features
- ❌ Reverse engineering or decompiling code
- ❌ Sharing repository contents externally
